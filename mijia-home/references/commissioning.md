# 设备调试：开关的有线/无线、双控、场景键

做场景之前先把开关调好。开关调错了，后面的场景再好也会出问题：灯关不掉、按键没反应，或者按一下灯闪两次。

## 第 1 步：看体检报告的「设备调试清单」

`home_report.py` 会逐个键列出应该怎么设。它的判断规则：

| 这个键 | 应设成 | 原因 |
| --- | --- | --- |
| 接着普通灯 | **有线（不改）** | 按键直接通断灯 |
| 双控的主开关（真正接着普通灯的那一路） | **有线，绝不改** | 改成无线后继电器常通，灯就关不掉了 |
| 双控的副开关（和主开关同名、没接灯的键） | 无线 | 按它时由双控规则切主开关那一路的继电器 |
| 接着智能灯（灯自己能调光） | 无线 + 来电上电 | 继电器常通，灯一直有电；按键只发事件，由规则控制灯 |
| 场景键（休闲模式、离开客厅…） | 无线 | 只发事件，不通断任何灯 |
| 看不出接的是什么（「左键」） | 问客户 | 接普通灯的改成灯名，场景键改成场景名 |

**同名的键 = 双控**：同一区域里，不同开关上名字一样的键（比如进门开关和两个床头开关都有「吸顶灯」），是同一盏灯。只有一路真正接着灯。

## 第 2 步：确认哪一路真正接着灯（双控时必须做）

不按名字猜。请客户在米家 App 里**单独关掉每个开关的那一路**，看灯灭不灭：
- 关了灯就灭的那一路是主开关，保持有线。
- 关了灯还亮的是副开关，改成无线。

问法：「床头左开关、床头右开关、进门开关都有一个『吸顶灯』键。请在米家 App 里分别点一下这三个键，告诉我点哪个的时候灯会灭。」

## 第 3 步：改成无线、设来电上电

做法：生成一条**一次性规则**，规则加载时把属性写进开关。不用客户在 App 里找菜单。

1. **查属性**。先看 `commissioning.KNOWN_SWITCH_MODES` 有没有这个型号（型号是 urn 第 6 段，例如 `tnv-sw2d01`）。
   - 有：`switch_mode_writes(did, urn, 第几键, wireless=True, power_on=接智能灯吗)` 直接给出要写的属性。
   - 没有：查 spec，`https://home.miot-spec.com/spec/<型号>`（把 `-` 换成 `.` 并补上品类，例如 `tnv.switch.sw2d01`），或 `https://miot-spec.org/miot-spec-v2/instance?type=<完整urn>`。在每一路的服务下找：
     - 「工作模式 / mode」：有「有线和无线」「无线开关」这类取值。有的型号有两个 mode 属性（基础的和扩展的），任选一个，以读回为准。
     - 「通电后状态 / default-power-on-state」：取「上电」那个值，只给接智能灯的那一路设。
2. **列给客户看**：哪几个键改成无线、哪几路设通电后上电，以及「接普通灯的键、双控主开关接灯的那一路保持有线」。客户同意了再往下做。
3. **生成规则**：`build_switch_mode_rule(rule_id, writes)`。规则是停用的，备注卡写明「一次性」。
4. **写入并启用一次**：按 `references/quickstart.md` 第 5 步的写入流程（计划 → 备份 → 客户发确认语 → 应用），应用后启用这条规则。
5. **读回核对**：读这几个属性，值对了就**停用或删掉这条规则**，免得网关每次重启都再写一遍。值不对，换另一个 mode 属性重试一次，还不对就停下，请客户在 App 里改：开关的设备页 → 设置 → 找「无线开关」或「按键模式」，接智能灯的那一路再把「通电后状态」设成开。
6. **查不到属性**：说明这款开关不支持无线模式。告诉客户这个键只能做有线用；接智能灯的，建议换支持无线模式的开关。不知道的就说不知道，不要编属性编号或 App 菜单名。

第一次碰到某个型号时，把查到的属性和读回结果记进 `进度.md`。

**绝不放进这条规则**：接普通灯的键，以及双控主开关接灯的那一路。改成无线后继电器常通，灯就关不掉了。

## 第 4 步：核对

改完一个键，请客户按一下：
- 接着智能灯、改成无线的键：灯不应被它直接断电；`mijia_read("logs")` 里能看到这次按键事件。
- 场景键：不通断任何灯，日志里有按键事件。
- 双控副开关：先做双控规则（`build_dual_control_rule`），按副开关，主开关那一路的灯应该切换。

都对了，再进入场景。

## 第 5 步：把结果写进台账

键名按「接普通灯用灯名、无线键写明用途」改好，用 `device_registry.py --set` 写进台账，例如：

```
--set "<did>=主卧床头左开关|主卧|吸顶灯·无线,筒灯·无线,床头吊灯·无线"
```

这样下次重新读设备、重新体检时，AI 不会再把副开关当成接灯的那一路。
